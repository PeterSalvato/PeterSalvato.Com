Dinner was the failure that made the pattern visible. Not one dinner. The accumulation. No plan by 4 PM. A grocery run that turned into two. Feeding the kids but not myself. Cross-contamination with gluten because the only option left was takeout from a place that couldn't guarantee safety. By evening, the executive function required to make a single decision about what to cook had already been spent on a hundred smaller decisions that started at breakfast.

The family's constraints clarified gradually. ADHD means working memory is a scarce resource. Autism means sensory regulation is architecture, not preference. Celiac means contamination isn't an inconvenience; it's a medical event. ARFID means the kids' relationship to food isn't about pickiness; it's neurological. One won't eat rice, noodles, or grains. The other doesn't prefer meat. I can't have gluten. Three different constraint profiles at the same table, every meal, every day.

None of these resolve. They compound. And any system built on the assumption that someone will remember, decide, sequence, or power through has already failed before 5 PM.

---

**Culinary modularity.** Five cuisine traditions organized by structural flavor elements: umami, acidity, heat, smoke. Each element present across all traditions. A small set of core techniques generates a large set of meals that can be split at the plating stage. The same base produces different versions for different constraints. Monday's braise becomes Wednesday's taco filling becomes Friday's rice bowl for the people who eat rice. The question "what's for dinner" is answered by the system before anyone has to think about it.

**Task sequencing as engineering.** Executive function isn't just about decisions; it's about sequencing. What happens in what order, what can run in parallel, what blocks what. Dinner prep runs like a build process: rice cooker starts first (longest lead time), protein defrosts while prep surfaces are cleared, vegetables go last. Morning routines are chunked the same way, each step small enough to execute without holding the whole chain in memory. The sequencing is externalized (posted, visible, repeatable) so it doesn't depend on someone's working memory to orchestrate.

**Accommodation as user experience.** Four people, four profiles. Each one has documented constraints: sensory thresholds, dietary tolerances, executive function patterns, regulatory needs. One can't process gluten. Two have ARFID with opposite restrictions. Sensory overload thresholds vary by person and time of day. Working memory capacity differs. Recovery patterns differ.

In any other context, this is a persona matrix. You document the users. You map their constraints. You design the system so it serves all of them without requiring any of them to adapt to a system that wasn't built for them. The kitchen layout, the meal architecture, the sensory zoning, the transition routines: each one is a design decision made against real user profiles, tested daily, revised when it fails.

The family doesn't experience the methodology. They experience a home that works for how they actually function, not how a household is supposed to function. That's the UX test. Not whether the system is elegant. Whether the people inside it can operate without fighting the environment.

**Celiac protocol as infrastructure.** Built into kitchen geography, not into anyone's memory. Separate prep surfaces, separate tools, separate cutting boards. When the family relocated internationally, the health infrastructure came with them, because the scaffold was externalized and documented, not carried in anyone's head.

---

This is ongoing. The constraints don't go away. The systems get better as we learn more.

When I can apply the systems, the house is smoother. My stress is lower. The kids eat. The evening isn't a scramble. When I can't, when the day outruns the structure, things fall apart the same way they always did. The systems don't fix the constraints. They make the good days more likely and the bad days less destructive.

The same principle runs through every project in this portfolio. [Savepoint Syntax](/governance/savepoint-syntax/) marks where thinking shifts so you can find it again when working memory drops it. [Formwork Protocol](/governance/formwork-protocol/) embeds decisions into the project itself so nobody has to remember what was already settled. The household needs both. The family's institutional memory is as fragile as any enterprise platform's, and the cost of losing it is dinner, not a deployment.
